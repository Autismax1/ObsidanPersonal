# Wanted Tags

[[Brotato]] › [[Shop Item Rolls]] › Wanted Tags

> [!summary] How wanted tags work
> On `5%` of item rolls (`10%` with a boost effect, e.g. [[Beast Master]]) the shop throws away every item without one of your character's wanted tags.
> Below: every shop item per tag, and which characters want it.
