# Doc Moth

[[Brotato]] › [[Items]] › Tier 2

## Effects
- Pet doc moth

## How it works
- Creates a zone. **While you stand in it:** HP regeneration heals twice as much (while below full HP), and every lifesteal proc heals 2 HP instead of 1. See [[Healing]].
- Zone size ×1 (×1.10 → ×2.10 when cursed).

- Max copies: 4. See [[Item Caps]].

- Shows up a bit more often for: [[Beast Master]], [[Bull]], [[Doctor]], [[Lich]], [[Masochist]], [[Pacifist]], [[Sick]], [[Vampire]]

Worst roll (+10%, wave 1) → best roll (+110%, wave 21+). Each effect rolls on its own. See [[Curse#Curse strength]].
