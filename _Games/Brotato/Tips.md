# Tips

[[Brotato]] › Tips

General strategy tips, one note each in `Tips/`. New tip: create a note in `Tips/` and insert the **Brotato Tip** template (command palette → *Templates: Insert template*).

- A tip that links a character (e.g. `[[Brawler]]`) appears in that character's **backlinks**.
- `verified`: `code` = checked in the game's code · `tested` = tried in a run · `community` = heard or read somewhere.
- Filter by topic with tags like `#brotato/tip/healing`.
