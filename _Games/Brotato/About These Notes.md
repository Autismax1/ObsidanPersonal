# About These Notes

[[Brotato]] › About

- **Source:** the game's own data and scripts, unpacked from `Brotato.pck` with REA (reverse engineering tool) and decompiled. Game files from 24 Nov 2026.
- **Checked in-game:** no. These are values from the code, and a patch can change them.
- **Names:** characters and items use their internal IDs, cleaned up. A few in-game names differ slightly.
- **Generated notes:** every note in `Characters/`, `Items/` and `Weapons/`, plus [[Items]], [[Weapons]], [[Weapon Classes]], [[Wanted Tags]], [[Item Groups]] and [[Item Caps]], was generated from the game data. On 26 Nov 2026 they were restructured so each fact appears once per note (the old layout is in the git history before that date). The generator is no longer on this machine, so regenerating would need a new script that writes this layout. Put your own notes in [[Tips]] and link the item instead.
- **Effect text** is built from the game's internal effect keys, so it is close to the tooltip but not word for word.
- **Cursed values** are computed with the game's own curse rules at the worst (+10%) and best (+110%) roll. A few effects with special curse rules are described in words instead.
- **Written by hand:** mechanic, shop and drop notes, summarizing the decompiled code.
